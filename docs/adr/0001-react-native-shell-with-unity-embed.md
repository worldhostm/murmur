# ADR 0001: 앱 셸은 React Native, 아바타 렌더는 Unity 임베드

날짜: 2026-11-06 · 상태: 승인 (기획안 "앱 스택 선택" 확정)

## 맥락

화면 대부분은 채팅 목록, 설정, 결제, 캐릭터 고르기 같은 일반 앱 UI이고, 고품질 실시간 3D 렌더가 필요한 곳은 통화 화면뿐이다. 실시간 대화가 본질이라 지연시간을 화질보다 우선한다.

## 결정

- 일반 화면은 React Native(TypeScript) 하나로 만든다.
- 아바타 렌더링은 Unity(URP)를 라이브러리로 임베드해 통화 화면에서만 쓴다.
- 트래킹(ARKit / MediaPipe)은 네이티브 모듈로 두고, Unity에는 `@murmur/face-protocol` 바이너리 프레임만 넘긴다.
- 0단계 PoC에서 RN↔Unity 연결과 카메라 소유권(어느 쪽이 카메라를 쥐는지)을 가장 먼저 검증한다.

## 대안

- Unity 단일 앱: 렌더 품질 최고, 그러나 일반 화면·결제·푸시가 불편하고 앱이 무겁다.
- 네이티브(Swift/Kotlin) + Unity: OS 기능 활용은 최고, 그러나 같은 화면을 두 번 만든다.

## 결과

- RN↔Unity 브리지 코드와 디버깅 층이 하나 늘어난다. 브리지는 `apps/mobile/src/avatar/` 어댑터 뒤에 둔다.
- 디자인 토큰은 TS와 C# 두 언어로 생성한다 (ADR 0003).
