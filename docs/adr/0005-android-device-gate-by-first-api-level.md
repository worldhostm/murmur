# ADR 0005: Android "2020년 이후 출시" 판정은 first_api_level로 한다

날짜: 2026-11-06 · 상태: 승인

## 맥락

기획에서 Android는 2020년 이후 출시 기기만 지원하기로 했다. Android는 출시 연도를 직접 알려 주지 않는다.

## 결정

`ro.product.first_api_level`(출하 시 API 레벨) ≥ 29 를 "2020년 이후 출시"로 본다. GMS 요건상 2020년 1월 31일 이후 출시 기기는 Android 10 이상으로 출하되어야 했기 때문이다. `minSdkVersion`도 29로 맞춘다. 판정 규칙은 JS 순수 함수에 두고 네이티브는 사실만 수집한다.

## 대안

- 모델명 허용 목록: 정확하지만 신제품마다 갱신해야 하고, 지역별 모델 변형이 많다.
- 성능 벤치마크 런타임 측정: 첫 실행이 느려지고 결과가 흔들린다. 나중에 보조 신호로 추가할 수 있다.
- `Build.VERSION.SDK_INT`만: 2017~2019년 기기가 Android 10으로 업그레이드되면 통과해 버린다.

## 결과

- `first_api_level`이 없는 기기는 `unknown`으로 통과시키고 비율을 지표로 본다.
- 스토어 쪽 필터(기기 카탈로그)는 별도 운영 작업으로 남는다. `docs/specs/device-support.md`.
