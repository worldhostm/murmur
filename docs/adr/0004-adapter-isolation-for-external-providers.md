# ADR 0004: 외부 공급자는 전부 어댑터 뒤에 둔다

날짜: 2026-11-06 · 상태: 승인

## 맥락

이 서비스는 트래킹(ARKit, MediaPipe), LLM, 음성 인식·합성, 실사형 모델, 얼굴 검출, 콘텐츠 안전 API 등 외부 의존이 많다. Ready Player Me 가 2025년 12월 인수된 뒤 2026년 1월 31일 공개 서비스를 종료했고, 이에 의존하던 앱들이 아바타 기능을 잃었다. 외부 서비스는 언제든 사라질 수 있다는 전제로 설계해야 한다.

## 결정

- 외부 공급자 호출은 모두 서비스 안의 어댑터 인터페이스(`src/adapters/types.ts`) 뒤에 둔다. 핵심 로직은 인터페이스만 본다.
- 모든 어댑터에 가짜 구현(`adapters/fake`)을 두고, 단위·통합 테스트는 가짜로만 돌린다. 외부 네트워크 없이 CI 에서 돈다.
- 공급자 교체는 어댑터 구현 하나를 추가하는 일이어야 한다. 핵심 로직이 바뀌면 설계 오류로 본다.
- 어댑터가 받는 입력은 face-protocol 프레임이나 그 파생 수치다. 원본 카메라 영상을 받는 어댑터는 만들지 않는다.

## 대안

- 공급자 SDK 를 직접 호출: 빠르지만 교체 비용이 전체 코드로 번진다.
- 범용 추상화 라이브러리 사용: 우리가 쓰는 인터페이스보다 넓고, 그 라이브러리 자체가 또 하나의 외부 의존이다.

## 결과

- `services/ai-character`(STT/LLM/TTS), `services/upload-check`(검사 엔진 4종), `services/signaling`(Transport) 이 이 규칙으로 구현되었다.
- 실제 공급자 어댑터는 각자 별도 스펙과 PR 로 추가한다.
