# 솔로 대화 신뢰성 개선

작성: 2026-11-11

## 탐색 결과와 우선순위

1. **이번 구현 — 대화 요청과 세션 수명 정합성.** 연속 전송하면 앞선 답을 버리는 구조이고, 친구 통화로 이동할 때 요청이 무효화되지 않는다. 같은 캐릭터 재입장은 화면 기록만 비우고 서버 세션을 재사용한다. 외부 서비스 없이 회귀 검증할 수 있고 핵심 대화 경험에 직접 영향을 준다.
2. **다음 — 기분 기록 저장과 조회.** 현재 저장 버튼의 콜백은 비어 있다. 로컬 저장·삭제·날짜별 조회 및 민감 정보 보관 정책을 함께 설계해야 한다.
3. **다음 — 통화 진입의 실제 연결.** 친구 통화가 현재 랜덤 매칭 PoC로 연결되고 음소거·신고 콜백은 비어 있다. 친구 초대와 매칭을 분리하고 시그널링 연결 전 완료된 통화 기능으로 취급하지 않는다.
4. **후속 — 기기 접근성과 렌더 품질.** 카메라 거부·미지원 기기에서 텍스트 대화를 허용하는 진입 구조, iOS Unity 준비 콜백, 실기기 성능 측정이 남아 있다.

## 범위와 구현 계획

- 한 대화에서 응답 요청은 하나만 진행한다. 동기 잠금으로 빠른 연속 입력도 막는다.
- 기다리는 동안 전송 버튼과 예시 문장을 비활성화하고 대기 문구를 표시한다. 다음 메시지 초안 작성은 허용하며 보내지 않은 초안은 유지한다.
- 최종 어댑터 실패는 안내하고 다시 입력할 수 있게 한다. 자동 재전송은 서버 중복 처리 가능성 때문에 하지 않는다. 기존 원격→스크립트 폴백 정책은 유지한다.
- 뒤로가기·친구 통화·언마운트 시 이전 요청의 성공/실패/완료 처리가 화면 상태에 영향을 주지 않는다. 네트워크 요청 자체의 취소와 서버 기록 삭제는 이 범위에 포함하지 않는다.
- 솔로 화면 이탈 시 화면 기록과 응답 상태를 비운다. 다시 입장하면 같은 캐릭터라도 앱이 생성하는 원격 어댑터와 세션을 새로 만든다. 주입한 테스트 어댑터의 수명은 호출자가 관리한다.

## 완료 조건

- 대기 중 전송·예시 문장을 눌러도 어댑터는 한 번만 호출되고 초안은 유지된다.
- 응답 후 다음 요청에는 앞선 사용자 메시지와 답이 순서대로 전달된다.
- 실패 안내 후 다시 메시지를 보낼 수 있다.
- 화면 이탈 후 늦은 성공/실패가 새 대화를 오염시키지 않는다.
- 같은 캐릭터로 재입장해도 원격 세션은 새로 생성된다.
- 모바일 테스트, 타입 검사, lint 통과.
