# 캐릭터 대화 경험 디자인 개편

2026-11-12 · 구현 계획

## 문제

이전 개선은 입력·타입 스케일을 정리했지만 모든 화면을 비슷한 텍스트와 버튼 목록으로 만들었다. 작은 초상, 반복된 전체 폭 버튼, 대화마다 붙는 이름/배지, 개발용 예시 문장 노출이 캐릭터와 대화의 우선순위를 낮췄다. 폰트 fallback을 적용하면서 Serif의 차이도 사라졌다. 새 폰트가 없어도 이미지 크기·면의 대비·텍스트 계층·행동 배치로 화면의 목적을 구분한다.

## 전 페이지 계획

| 화면 | 방향 | 구현 |
| --- | --- | --- |
| 온보딩 | 조용한 캐릭터 라운지 | 브랜드 워드마크, 물결 모티프, 실제 캐릭터 초상과 짧은 초대 문장, 하나의 주 행동 |
| 캐릭터 선택 | 누구와 이야기할지 비교 | 더 큰 초상, 이름/역할 중심, 세계관은 보조, 선택 시 명확한 테두리와 표시 |
| 솔로 채팅 | 캐릭터와 나의 대화 | 헤더 AI 고지 유지, 연속 메시지 그룹화, 예시 문장은 접기, 둥근 입력 도크, 작고 명확한 보내기 |
| 기분 기록 | 개인 노트 | 기록 날짜·짧은 안내·넓은 작성 영역, 작성/조회 세그먼트, 기록별 날짜/삭제 구분 |
| 친구 연결 | 초대장 | 초대/입장 세그먼트, 초대 설명과 상태 패널, 코드 카드, 랜덤 매칭은 접힌 보조 영역 |
| 미지원 기기 | 대안 안내 | 물결 모티프와 텍스트 대화 제안, 기기 사유는 정보 카드, 하단 시작 행동 |
| 표정 미리보기 | 카메라 리허설 | 실제 미리보기 영역/권한 상태/텍스트 전환의 계층, 통화로 오인시키지 않음 |
| 통화 컴포넌트 | 아바타 중심 | 안전 영역과 상태 패널, 하단 컨트롤 도크, 읽을 수 있는 종료 라벨. 아직 사용자 연결 경로에 실제 음성 통화를 추가하지 않음 |

## 공통 규칙

- 기존 색상·타입·간격 토큰 사용. 새로운 그라데이션·그림자·장식 이모지를 추가하지 않는다.
- 모든 페이지를 카드로 감싸지 않는다. 강조하는 면(초대/캐릭터)과 여백(본문)을 교대로 쓴다.
- AI 표시는 헤더에 항상 유지. 메시지 그룹의 첫 메시지에 발신자 정보를 표시하고 반복은 줄인다.
- 세그먼트는 선택 배경과 접근성 선택 상태를 함께 쓴다. 버튼 터치 영역 48 이상.
- 작은 화면/큰 글자는 세로 배치. 기록·채팅 초안 보존, 새 메시지 스크롤 동작 유지.
- 기존 에셋은 137×240이므로 과도하게 확대하지 않는다. 고해상도 원화 교체는 후속.

## 실행과 검증

1. 실행 문제를 Metro 의존 개발 APK와 번들 포함 미리보기 APK로 구분한다.
2. 공통 모티프·세그먼트, 온보딩/선택을 구현한다.
3. 채팅/기록, 연결/상태/통화 컴포넌트를 구현한다.
4. 동작 테스트와 두 테마 스냅샷, 대비·타입·lint, Android JS 번들 생성을 확인한다.
5. 에뮬레이터 실행이 가능한 환경에서 스크린샷 검수한다. 정적 테스트를 실제 기기 시각 검증으로 보고하지 않는다.

### 번역 키 노출 수정

- Fast Refresh 후에도 유지되는 i18next 인스턴스에 최신 한국어·영어 리소스를 다시 등록하고 구독 화면에 갱신을 알린다. 선택 언어는 유지한다.
- 범위는 번역 리소스 갱신이며, Metro 연결이나 APK 번들 누락 오류와는 별개다.
- 완료 조건: 채팅의 `design.*` 문구가 한국어로 해석되고, 초기화된 인스턴스의 누락·이전 번역이 갱신되며 선택 언어와 화면 갱신 알림을 테스트한다.
- 번역 테스트 6개, 모바일 타입 검사, 변경 TypeScript 파일 ESLint 통과. 에뮬레이터 표시 확인은 별도다.
