# 스펙: 모바일 앱 셸 (테마·i18n·핵심 컴포넌트·화면 뼈대)

상태: 구현됨 (2026-11-06)

## 목적

DESIGN_SYSTEM.md의 규칙을 코드로 고정한 React Native 셸. 이후 모든 화면은 이 테마 레이어와 컴포넌트 위에 올린다.

## 범위

- `resolveTheme` (§2 로직 그대로) + `ThemeProvider`/`useTheme`, OS "동작 줄이기" 감지
- i18n (ko/en), 재촉 문구 금지·해요체 검사
- 컴포넌트: 주/보조 버튼, 말풍선(내/상대/AI), AI 캐릭터 표시, 캐릭터 카드, 통화 컨트롤, 말하는 중 물결 표시, 기분 카드, 화면 바탕
- 화면 뼈대: 온보딩, 캐릭터 고르기, 솔로 모드, 통화 화면(AI·사람 공용)
- 임시 내비게이터로 온보딩 → 캐릭터 고르기 → 솔로 → 통화 흐름

## 범위 밖

- 네이티브 프로젝트(ios/, android/) 생성, Unity 임베드, 카메라·트래킹 네이티브 모듈
- react-navigation, 상태 관리, 서버 연결
- 글꼴 파일 번들 (README로 절차만)
- 방 통화 다중 타일, 신고 사유 선택 시트, 위기 안내 화면 (문구는 i18n에 준비됨)
